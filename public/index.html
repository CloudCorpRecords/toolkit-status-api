Toolkit Status API

A small serverless API running on Vercel Edge Functions (TypeScript, zero infrastructure to manage). It reports live status for the Greenlight open source toolkit: npm package versions and GitHub pull request counts, fetched from public upstream APIs at request time.

Endpoints

  • GET /api/health — service health and runtime
  • GET /api/toolkit — latest npm versions for @reneturcios/greenlight, prwatch, claimcheck, gatefile
  • GET /api/github — live authored PR counts for CloudCorpRecords
